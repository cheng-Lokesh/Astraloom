# Project Astraloom 白皮书实现基准

来源：`白皮书_补齐版_v35_VibeCoding实施协作手册版.docx`

本文件是后续产品与工程实现的约束基准。任何实现与白皮书冲突时，以白皮书为准。

## 1. 产品定义

Project Astraloom 不是传统算命、心理咨询、CRM、聊天机器人或普通报告工具，而是 AI Life Simulator / 个人数字生命沙盘模拟器。

核心体验不是“回答用户一个结论”，而是：

1. 收集用户的现实困境和关键人物。
2. 生成用户主分身、平行分身和关键 NPC。
3. 构建只读关系图谱。
4. 运行一镜到底的短窗口或长期趋势推演。
5. 产生 Event Log、Claim 和证据链。
6. 用沙盘、时间线和报告交付可复盘结果。
7. 用反馈校准下一次推演。

## 2. 四条不可违反底线

1. 个体沙盘优先：最小单位是 Agent，不是抽象事件或长文结论。
2. 免费层低成本：免费预览展示真实但模糊的沙盘异动，不做免费高成本 NPC 深扫。
3. 图谱只读：关系图谱是证据视图，不是用户可编辑的关系管理器。
4. 安全降级不可绕过：高风险内容先降级，再决定是否生成；付费不能绕过安全。

## 3. MVP 必须围绕的闭环

白皮书定义的 MVP 闭环：

`问题定义 -> 情境倾诉 -> 身边人抽取 -> Agent 生成与确认 -> 关系图谱构建 -> 一镜到底推演 -> 沙盘主屏展示 -> 战报解锁 -> 用户反馈校准`

当前阶段允许用本地确定性算法模拟，但页面和数据结构必须朝这个闭环收敛。

## 4. 当前产品方向修正

后续不应继续把产品做成“用户填表 -> 系统给摘要”的决策工具。必须转向：

- 输入像倾诉，而不是问卷。
- 确认像整理关系，而不是配置参数。
- 推演像观察生态变化，而不是等待报告生成。
- 报告像证据链复盘，而不是独立玄学文章。
- 付费像解锁完整事件链、具体 NPC、分身差异和策略手册，而不是制造恐惧。

## 5. 页面实现优先级

短期优先级：

1. `/intake`：推演入口和倾诉采集，支持 Track A/B、时间窗口、主问题、可选背景、禁止行动边界。
2. 人物确认流：自动抽取人物，用户确认/删除/重命名，不手动编辑边权。
3. 只读关系图谱：显示用户、平行自我、关键 NPC、关系类型、强度区间、置信度和证据入口。
4. 推演运行页：展示冻结图谱、生成 tick、写入 Event Log、计算 Claim 的阶段感。
5. 结果沙盘页：图谱、时间切片、结论卡、Timeline Feed、证据链联动。
6. 报告页：核心判断、关系变化、关键事件、风险信号、行动建议、证据链、免责声明、复盘入口。
7. 付费页：明确解锁完整事件链、具体 NPC、平行分身差异、策略手册、退款/失败/安全降级说明。
8. 反馈/历史页：用户标记 Claim 是否命中，并回写校准记录。

## 6. 禁止事项

- 不做算命 App、读心工具、伴侣监控、确定预测或专业建议替代。
- 不承诺“必然发生”“已经注定”“对方一定会”。
- 不用恐惧文案逼迫付费。
- 不让付费改变结论方向或提高确定性。
- 不把关系图做成可编辑 CRM。
- 不在免费层常态调用高成本深度推演。
- 不在没有 Event Log 和 evidence_refs 的情况下展示强 Claim。
- 不一次性实现整份白皮书；每次只做一个有验收标准的小模块。

## 7. 付费价值定义

用户付费购买的是深度和证据，不是更确定的命运：

- 具体 NPC 的完整影响路径。
- 完整 Event Log 和关系边 before/after。
- 平行分身差异。
- 关键变量解释。
- 可执行策略手册。
- 复盘和反馈校准能力。

## 8. 验收标准

每次实现必须至少验证：

- 用户是否能更快完成一次可信的个体沙盘推演。
- Agent 是否像用户和身边人。
- 关系图谱是否是核心体验，而不是装饰。
- 结论是否能回到 seed_context、agent_profile、relation_edge、simulation_tick、event_log 或等价本地证据。
- 付费点是否回到证据链和策略深度。
- 高风险输入是否先降级。
- 页面是否没有工程词、乱码、恐吓、确定性命运表达和专业建议越界。

## 9. 下一步建议任务

下一步不应继续泛化美化页面，而应实现白皮书中更关键的“人物确认 + 只读关系图谱”：

- 从 `/intake` 的自然语言中抽取 5-8 个候选人物。
- 给每个人物生成角色、关系、动机、资源/权力、当前压力、置信度、证据来源。
- 让用户用自然语言或简单按钮确认/删除/重命名。
- 保存为本地 Agent/NPC 草稿。
- 在一个只读关系图谱页展示节点和关系，点击节点可看证据，不提供边权编辑器。

这比继续优化报告文案更符合白皮书，因为用户首先要相信“沙盘里真的放进了我和我身边的人”。
