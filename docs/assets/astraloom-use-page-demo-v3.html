开始一个真实处境沙盘

先说你正在面对什么。
一句话也可以。

Astraloom 会先读取现实处境，再把时间气候作为轻量镜头，生成几种可观察的路径。你不需要先填一长串表格。

你的问题或处境 仅使用你确认的材料
例如：我最近在考虑要不要离开现在的工作。主管态度变得模糊，但外部机会还不稳定，我想知道接下来三个月应该观察什么、怎么行动。

系统只会追问必要信息

如果一句话足够清楚，会直接进入沙盘；如果缺少关键边界，最多追问 1-3 个问题。

命理不是事实来源

它只调整你的压力反应、边界风格和时机敏感度；现实事实仍以你的材料为准。
